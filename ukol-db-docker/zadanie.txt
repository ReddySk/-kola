Vytvořte dva Docker kontejnery, které spolupracují pomocí docker build a docker run:
MariaDB kontejner – běžící databázový server.
Python kontejner – načítá data z CSV souboru, transformuje je a ukládá do MariaDB.

Vše nakonec zpusťte přes docker-compose.yml

Kromě zdrojového kódu, Dockerfiles a docker-compose popište celý postup vašeho řešení v souboru README.md, který umístíte do složky s vaším cvičením.

Bonus: vytvořte HTTP REST server jako třetí kontejner, který bude uložená data nabízet pomocí metody GET
